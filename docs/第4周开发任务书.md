## 本周面试考点速查

| 问题 | 关键回答 |
|------|----------|
| RAG在线流程的步骤？ | 问题向量化→Milvus检索Top-K→拼接Prompt→大模型生成→返回答案+来源 |
| 为什么问题也要向量化？ | Milvus是向量搜索，查询向量和存储向量在同一向量空间才能比较相似度 |

| sources字段的作用？ | 可追溯性 — 用户知道答案来自哪些文档块，增强可信度 |
| DeepSeek API是OpenAI兼容格式？ | 是的，请求体结构（model+messages）和响应结构（choices）完全一样 |
| 为什么先存用户问题再处理？ | 即使后续流程失败（API超时等），用户的问题记录也保留了 |
| 级联删除的顺序？ | 先删子表（消息）再删父表（会话），否则留下孤儿记录 |
