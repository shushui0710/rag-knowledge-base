## 二、5 条链路图（背下来，白纸能画）

```
① RAG 离线入库：文档上传 → MinIO → 解析(PDF/Word) → 滑动窗口分块 → 智谱 Embedding → Milvus 存向量
② RAG 在线问答：提问 → Embedding → Milvus 检索TopK → Prompt拼接 → DeepSeek → 答案+来源
③ 阶段2 检索链：提问 → LLM查询改写 → 混合检索(稠密+BM25稀疏，召回20) → Rerank精排(取5) → Prompt
④ 阶段3 Agent：提问 → [意图路由] → 走问答链路 或 AgentExecutor(ReAct：思考→调工具→观察→再思考，≤5轮)
⑤ 阶段3 认证：请求 → JwtInterceptor 验签 → UserContext(ThreadLocal) → 业务按 userId 隔离
```

## 三、10 个必问话术（答 → 追问预案）

1. **"RAG 为什么能减少幻觉？"** → 检索真实文档片段作为 Prompt 依据，模型"照着资料答"，不靠记忆硬编。
   追问"检索不到怎么办？" → 阈值过滤 + 兜底文案，不让 LLM 瞎编。

2. **"为什么用向量检索，不用 LIKE？"** → 语义匹配："机器不转了"能搜到"设备停机故障"；LIKE 只能精确匹配。
   追问"向量检索的缺点？" → 精确匹配失效（编号/型号）→ 所以加 BM25 稀疏路做混合检索。

3. **"混合检索怎么融合？"** → 双路召回（稠密+稀疏）→ 按 `alpha*稠密分 + (1-alpha)*稀疏分` 加权求和 → 降序取 TopK；alpha 用测试集调。
   追问"分数尺度不一致？" → 用 RRF 倒数排名融合替代加权和。

4. **"召回和精排为什么两段式？"** → 向量检索快但粗（双塔），Rerank 准但慢（交叉编码）→ 先召回 20 再精排 5。
   追问"Rerank 挂了？" → 降级按原分数排序，主流程不挂。

5. **"查询改写做什么？"** → 口语 → 检索词（LLM 一次廉价调用）。⚠️ 检索用改写，回答 Prompt 仍用原问题。
   追问"改写失败？" → 返回原问题兜底。

6. **"Function Calling 是什么？"** → 把工具（函数名+描述+参数schema）传给模型，模型返回结构化的 tool_calls，我们执行后回填结果，再让模型继续推理。
   追问"和让模型输出 JSON 的区别？" → tool_calls 是模型训练对齐过的原生格式，结构化稳定，不用在 Prompt 里约束格式。

7. **"ReAct 循环怎么防死循环？"** → maxIterations=5 上限 + 熔断器（连续失败5次→熔断60s）+ 工具执行 try-catch 回填错误信息。
   追问"tool 消息报 400？" → 必须先原样回填 assistant(tool_calls) 消息，tool_call_id 必须配对。

8. **"多用户数据怎么隔离？"** → JWT 拦截器解析 token → UserContext（ThreadLocal）持有 userId → 所有查询加 `eq(userId)`，工具内也隔离。
   追问"ThreadLocal 内存泄漏？" → 拦截器 afterCompletion 里 remove。

9. **"Agent 的意图路由怎么设计？"** → LLM 分类（DOCUMENT/STATS/HYBRID），失败默认回落 DOCUMENT（宁可多检索）。
   追问"成本控制？" → 路由只用一次廉价 LLM 调用（temperature 0.1）。

10. **"记忆/反思/容错各解决什么问题？"** → 记忆=跨轮上下文（旁路增强，失败静默降级）；反思=LLM 自评回答质量（解析失败默认放行）；熔断/降级=第三方不可用时保主链路。

## 四、笔试/机试手撕清单（八股，与项目无关，但高频）

| 高频题 | 必须会 |
|--------|--------|
| 单例 | DCL + volatile 双重检查（能默写） |

> ⚠️ 手撕考的是这些通用基础，**不是项目代码**。项目是谈资，八股才是笔试分。

## 五、开场话术模板（30 秒版）

> "我做的是一个 RAG 智能知识库问答平台：文档上传后解析分块、向量化入库，用户提问时检索相关片段交给大模型回答，附带来源引用。最近把它演进成 Agentic RAG——通过 Function Calling 让助手能自主决定'查文档、查统计还是生成报告'，检索侧升级了 Milvus 2.5 的 BM25 做混合检索，同时加了重排、查询改写、长期记忆和反思这些增强组件，核心亮点是三层降级策略保证主链路可用。"

（说完等面试官挑感兴趣的点深挖——挑中的基本都是 A 档，你已经准备好了。）
