- **面试**：速记卡（30 分钟）→ 亮点难点（1 天）→ 学习笔记（1 周）
- **写代码**：以代码注释为准；评估用 `eval/`
- **不再维护**：演进辅导方案/周任务书/过程审查报告已删除（教学价值已并入代码注释与学习笔记）
