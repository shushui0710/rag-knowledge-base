## 📖 使用建议

- **面试**：速记卡（30 分钟）→ 技术亮点（1 天）→ 学习笔记（1 周）
- **写代码**：只看「演进辅导方案」的 📁 目录定位 + 【标准答案】
- **不需要读**：骨架说明/审查报告/任务书（内部过程文档）
