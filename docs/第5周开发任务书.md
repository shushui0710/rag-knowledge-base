## 为什么需要这些改动

### 1. Markdown 渲染（TODO 1）

DeepSeek 的回答天然是 Markdown 格式：
```
## 回答
根据文档内容，RAG 的流程如下：
1. 文档分块
2. 向量化
3. 检索
```

当前用 `{{ msg.content }}` 显示，用户看到的是一坨带 `#` 和 `1.` 的纯文本。用 `markdown-it` 渲染后，会变成格式化的标题和有序列表。

`markdown-it` 已在 package.json 中安装（v14.1.0）。

### 2. 自动滚动（TODO 2）

AI 回答通常很长，新消息会超出可视区域。不自动滚动的话，用户每次都要手动拉到底部才能看到回答。

### 3. 路由监听（TODO 3）

当前 `onMounted` 只在组件首次挂载时加载历史。用户在侧边栏点击另一个会话时，URL 变了但 `onMounted` 不会再次触发（组件没销毁重建），导致历史不刷新。

需要 `watch` 监听 `route.params.sessionId` 的变化。

### 4. 自动标题（TODO 4）

新会话标题都是"新对话"，侧边栏一排"新对话"根本分不清。第一条消息后，用问题前 20 字作为标题。

### 5. 删除会话（TODO 5）

侧边栏没有删除入口，会话越积越多无法清理。
