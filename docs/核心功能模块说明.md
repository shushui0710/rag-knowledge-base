# 核心功能模块说明

> 文档版本：2026-08-13（实测验证版）｜ 模块清单与关键实现均与源码一致

## 模块总览

| 模块 | 包路径 | 职责 |
|------|--------|------|
| auth 认证 | `com.liushuwen.rag.auth` | 注册/登录/当前用户（JWT + BCrypt） |
| document 文档 | `com.liushuwen.rag.document` | 上传/解析/分块/向量化/分类/删除/增量更新 |
| chat 问答 | `com.liushuwen.rag.chat` | 会话管理、RAG 问答、LLM 调用（chat/chatWithSystem/chatWithTools） |
| agent Agent | `com.liushuwen.rag.agent` | 工具抽象与注册表、ReAct 执行器、多 Agent、熔断、指标 |
| rag 检索增强 | `com.liushuwen.rag.rag` | 混合检索、Rerank、查询改写、意图路由、记忆、反思 |
| common/config | `com.liushuwen.rag.common/config` | 统一响应/异常、JWT 拦截器、配置类 |
| eval 评估 | `com.liushuwen.rag.eval` + test | 检索命中率评测 |

---

## 一、认证模块（auth）

- **注册**：BCrypt 加密 + 用户名查重（实测：重复注册 400"用户名已存在"）
- **登录**：BCrypt 验证 + JWT 签发（HS256，24h）；**统一错误提示防枚举**（实测：错误密码/不存在用户均返回"用户名或密码错误"）
- **认证链路**：`JwtInterceptor.preHandle` 验签 → `UserContext(ThreadLocal)` 持有 userId → `afterCompletion` 清理（防泄漏）
- **接口**：`/api/auth/register` / `/api/auth/login` / `/api/auth/me`（仅 login/register 免认证）

## 二、文档模块（document）

- **上传**：MinIO 存文件 → PDFBox/POI 解析 → 滑动窗口分块（512 字/64 重叠）→ 状态管理（0 待入库/1 已入库/2 失败）
- **向量化**：智谱 embedding-3（2048 维）批量调用（实测：242 块 4.06s）
- **检索存储**：Milvus 2.5（稠密 FloatVector + BM25 SparseFloatVector 双路）
- **增量更新**：先删 MySQL 分块 + Milvus 向量，再重新解析入库（保持一致性）
- **删除**：逻辑删除 + 存在性校验（2026-08 验收修复）
- **接口**：upload / list（按用户+分类过滤）/ embed / delete
- **边界实测**：空文件 400、非法格式 400、删除不存在文档 400

## 三、问答模块（chat）

- **会话**：创建/列表/删除（级联删消息）/历史
- **RAG 问答链路**：查询改写 → 混合检索(召回20) → Rerank(精排5) → Prompt 模板 → DeepSeek 生成 → 答案+来源引用（实测：HashMap 问答 5.9s，来源 score 1.0 精准命中）
- **阈值过滤**：min-score=0.35，低分片段不进 Prompt；全空走兜底文案（防幻觉+省钱）
- **LLM 服务**（LlmService）：
  - `chat(prompt)`：标准对话（固定 system）
  - `chatWithSystem(system, user, temp)`：可控 system/temperature（改写/路由/评审共用）
  - `chatWithTools(messages, tools)`：Function Calling，返回 `LlmResponse`（ANSWER/TOOL_CALL 两态）；**思考型模型适配**：消息带 `type`、回填 `reasoning_content`（2026-08 实测修复）
- **接口**：session / sessions / ask/{sessionId} / history / session 删除

## 四、Agent 模块（agent）

| 组件 | 说明 |
|------|------|
| `Tool` 接口 + `ToolRegistry` | 工具抽象（name/description/schema/execute）；Spring 自动收集所有工具 Bean（策略模式） |
| 工具1 `QueryDocumentStatsTool` | 文档统计（用户隔离） |
| 工具2 `QueryDocumentListTool` | 文档列表（分类过滤 + limit） |
| 工具3 `GenerateReportTool` | 报告生成（RAG 检索 + 报告 Prompt） |
| `AgentExecutor` | **ReAct 循环**：LLM→tool_calls→执行工具→回填→循环≤5 轮；工具失败回填错误文案让 LLM 调整；熔断+指标 |
| `AgentMetrics` | 每日问答数/耗时/LLM/工具调用统计 |
| `LlmCircuitBreaker` | 连续 5 次失败熔断 60s |
| **接口** | `/api/agent/ask`（实测：统计问答 3.9s 真实调工具） |

## 五、检索增强模块（rag）

| 组件 | 实现 | 降级 |
|------|------|------|
| `RerankService` | 智谱 rerank（交叉编码），召回20→精排5 | API 失败按原分排序 |
| `QueryRewriterService` | LLM 口语→检索词（\|分隔解析） | 失败返回原问题 |
| `RouterService` | LLM 意图分类 DOCUMENT/STATS/HYBRID | 失败回落 DOCUMENT |
| `MemoryService` | 问答对存 qa_memory collection，score>0.5 召回 | 失败静默（不阻断） |
| `CriticService` | LLM 评审回答（pass/reason JSON） | 解析失败默认放行 |
| 混合检索 | `MilvusService.hybridSearch`：v1 稠密 + v2 BM25 稀疏 + alpha 融合 | collection 未重建时降级纯稠密 |

## 六、评估模块（eval）

- `EvalCase` + `docs/eval/questions.json`（5 题示例，可扩展 20 题）
- `EvalRunnerTest`（@SpringBootTest）：Top5 关键词命中率，单条失败 catch 继续
- 运行：`mvn.cmd test -Dtest=EvalRunnerTest`
